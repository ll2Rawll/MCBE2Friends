    MCXboxBroadcast #165

    Setup guide

    How do my friends join?
    1. Add the broadcasting account’s Xbox gamertag as a friend.
    2. Wait for the request to be accepted. If automatic acceptance is off, accept it on the broadcasting account.
    3. In Minecraft Bedrock, open Play → Friends and select the account’s joinable session.
    Where do I find the server address?

    Use the join address and Bedrock port from your hosting panel or server owner. The usual port is 19132. For Geyser, use its Bedrock listener. A name like play.example.net:19132 can be pasted into the address field.

    What do I need to run a broadcast?

    Keep an existing compatible Bedrock or Geyser server running. Build 165 targets Bedrock 1.26.60 and uses NetherNet HTTP signaling. The launcher needs internet access and downloads MCXboxBroadcast and Java 21 if needed.

    Which Microsoft account should I use?

    Use a dedicated Microsoft account with an Xbox profile and gamertag. Friends will add this account. Microsoft handles sign-in on its own website. MCXboxBroadcast saves the sign-in on this computer for future launches.

    Why can’t my friends see or join the server?

    Check that the launcher shows Broadcast live and that the accounts are Xbox friends. Check multiplayer and online visibility permissions, compatible Minecraft versions, and that the server address is reachable. The Activity tab shows connection problems reported during setup.

    Does the launcher need to stay open?

    Keep the computer awake and the launcher running. You can close this browser tab and reopen Mcbe2Friends to return. Stop broadcast takes the session offline. Quit launcher stops the session and exits the app.
